# Other Asia-English MEZASTAR sets (research)

Collected from the official Asia site (world.pokemonmezastar.com/sg/tag/...). Facts only; no images or prose copied.

## Series order on the official site

The tag page's "Go to a different Version" switcher lists, in this order: Stardust Version 1 (id 28933), Version 2 (31437), Version 3 (33112, already in the app), Version 4 (34928), Galaxy Version 1 (36251), Galaxy Version 2 (37860), Galaxy Version 3 (39325). The site gives no release dates. Codes: `1-<version>-NNN` for Stardust, `2-<version>-NNN` for Galaxy; Regular Tags `R-<series>-<n>` (Stardust R-1-1..3 in V2/V3/V4; Galaxy R-2-1..3 in all Galaxy versions).

There are **no older series before Stardust** on the Asia site: Stardust V1 is the first set listed. The "Super Tag Battle / Double Chase / Gigantamax-era" naming is from the Japanese releases and was not found on the Asia site (Galaxy is the Asia set that follows Stardust V4 and introduces Double Move, Chain Tag and Gigantamax tags).

## Reading the tables

- Grade: the page groups tags as Superstar (codes 001-010, recorded as 6), Star (011-025, 5) and "2~4 stars" (026-070, shown `?(2-4)`; per-tag grade not on the page). Regular Tags `?`.
- Types: main-series Pokedex types for the form (not on the page). Zacian/Zamazenta assumed Crowned forms where Behemoth moves are named.
- move / gimmick: only what the page's feature sections state. Gimmick lines: Dynamax, Z-Move, Mega, Gigantamax, Double Move, Chain Tag, TAG Move. Blank (`-`) means the page names nothing.
- confidence: `official` = code/name/tier/gimmick from the official page; `community` = official page but with an inferred mapping (noted); `guess` = unclear. Types are Pokedex knowledge throughout. No community wiki was used.
- Numbers refer to what each page lists; where the same Pokemon appears twice (e.g. a Star tag and a final-evolution tag), the page's gimmick text is attached to the Superstar/Star tag only.
